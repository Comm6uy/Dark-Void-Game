# Dark Void
Атмосферная казуальная аркада-лабиринт с хоррор-элементами. Свет — твоё оружие и твой единственный глаз.

## О проекте
Dark Void — казуальная аркада-лабиринт, в которой игрок управляет персонажем в полной темноте. Единственный источник света — ручной фонарь с конусным лучом. Игрок должен найти ключ и выбраться из лабиринта, избегая врагов, которые боятся света, и ловушек, которые видно только под лучом.

**Жанр**: Casual Arcade / Horror / Labyrinth. Платформа: PC (Web) / Mobile — Яндекс.Игры. Движок: Unity 6 LTS.

## Геймплей
Управление: WASD — движение персонажа, мышь — направление конусного луча фонаря, R (или тап по экрану после смерти) — мгновенный перезапуск уровня.

Задача уровня: найти ключ и найти выход.
